# UBIQUITOUS_LANGUAGE.md

Единый язык проекта. Термины используются одинаково в коде, документах, тестах,
коммитах и обсуждениях. Новые термины добавляются аналитиком в рамках задачи
(см. `docs/task/README.md`) и утверждаются человеком на гейте G1.

## Правила

1. Один термин — одно значение. Если термин перегружен — разделить.
2. Термин из предметной области живёт в коде как есть (`Secret`). После
   миграции 002–007 новый код, домен и документация используют только целевые
   термины; `Paste` — историческое имя, допустимое лишь в замороженных
   публичных идентификаторах переходного периода (см. «Переходные публичные
   имена»).
3. Синонимы фиксируются в колонке «Не использовать».
4. Язык терминов — английский (код), описание — русский.

## Термины

| Термин | Значение | Не использовать |
|---|---|---|
| Secret | Зашифрованная запись, созданная отправителем; агрегат ядра | Note |
| Paste (legacy) | Историческое имя `Secret` до миграции 002–007; сохраняется только в переходных публичных идентификаторах (см. ниже) | В новом коде, домене и документации |
| Plaintext | Открытый текст до шифрования или после успешной расшифровки | Текст, Message |
| SecretKey | Секретный ключ, вводимый пользователем; сервером не хранится | Password, Пароль |
| Hint | Необязательная публичная подсказка к ключу | Description |
| Token | Публичный идентификатор Secret в URL | Id, Code |
| Ttl | Срок жизни Secret от создания до истечения | Lifetime, Expiry |
| Expiration | Момент, после которого Secret недоступен | Expire date |
| Reveal | Успешная расшифровка и показ Plaintext | Decrypt (на уровне UI) |
| Burn-after-reading | Режим, при котором Secret удаляется после первого Reveal | One-time |
| Purge | Физическое удаление истёкших Secret | Cleanup, Delete |
| EncryptedPayload | Набор salt + nonce + ciphertext для одного Secret | Cipher, Blob |
| Cryptography | Порт шифрования/расшифровки | Encryption (для интерфейса) |
| Owner | Владелец Secret при появлении аккаунтов (планируется) | User |
| AuditEntry | Запись журнала действий (планируется) | Log, Event (в значении Audit) |

## Переходные публичные имена (временно легаси)

Миграция 002–007 завершена, но ради неизменности наблюдаемого поведения
(ссылки, формы, маршруты, cron, том БД) часть публичных идентификаторов
сохраняет исторический корень `paste`. Они переименовываются в `secret`
отдельной задачей; на первом шаге URL и wire-контракты не меняются:

- команда `app:paste:purge` и строка в `src/Schedule.php`;
- имена маршрутов `app_paste_view`/`app_paste_created` (URL `/p/{token}`,
  `/created/{token}` не меняются);
- wire-контракты форм `create_paste[...]`/`unlock_paste[...]` и `csrf_token_id`;
- каталог `templates/paste/*` и DOM-id `#paste-url`;
- docker-том `paste_data`.

Это технические идентификаторы, а не доменные термины: в новом коде они не
вводятся, а домен и документация используют `Secret`. Вне этого раздела `Paste`
сохраняется только в исторических артефактах решений (ADR, `docs/task/<id>/`) и
в именах тестов переходного периода (например, `PasteFlowTest`,
`RenamePasteToSecretMigrationTest`), но не в новом коде и не в домене.

## Термины-кандидаты (обсуждаются)

- **Attachment** — файл, привязанный к Secret (при появлении загрузки файлов).
- **Quota** — лимит ресурсов для Owner/тарифа.
- **Moderation** — действия администратора над нарушающими правилами Secret.
